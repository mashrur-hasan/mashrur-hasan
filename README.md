* **Contribution:** Developed a computational pipeline connecting SIMP density fields to variable-thickness lattice structures and manufacturing toolpaths via k-d tree interpolation; validated with 3D-printed specimens under quasi-static mechanical bending tests.

### 2. 📄 Representation-Aware Solver-in-the-Loop Learning for Topology Optimization
* **Status:** Submitted Manuscript (*Engineering Reports*) · *Available upon request*
* **Focus:** Investigated "gradient conflict" when embedding differentiable SIMP solvers into grid-based CNNs vs. graph-based neural networks (GNNs); evaluated PCGrad gradient surgery across 500 evaluation cases and developed graph-search algorithms for connectivity-safe structural reconstruction.

### 3. 📄 Architecture-Dependent Mechanical Response and Voxel-FEA Calibration in Topology-Optimised FDM Structures
* **Status:** Submitted Manuscript (*Advances in Materials Science and Engineering*) · *Available upon request*
* **Focus:** Combined active-mask SIMP formulations, ISO 604 quasi-static compression testing, transverse-isotropic voxel-FEA calibration, and Gaussian Process surrogates with SHAP feature attribution to resolve simulation-to-experiment discrepancies in 3D-printed porous components.

### 2. ⚙️ [Wooden Planetary Gear System](https://github.com/mashrur-hasan/Wooden-Planetary-Gear)
